# 3CA Design

Temporary portfolio / landing page for 3D scanning, CAD services, and 3D printing.

## Features
- Modern Norse-inspired dark theme (blue + orange)
- Pure HTML5, plain CSS, and minimal vanilla JavaScript
- Responsive layout with mobile menu
- One-way contact via email and phone
- Placeholder images (replace later)

## Deploy to GitHub Pages
1. Go to repository **Settings → Pages**
2. Under “Build and deployment”, set Source to **Deploy from a branch**
3. Select branch **main** / **/(root)** and save
4. Site will be available at: https://l-gothberg.github.io/3CADesign/

Placeholder images use placehold.co and can be swapped for real project photos by editing `index.html`.
